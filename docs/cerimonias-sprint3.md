# Cerimônias Scrum — Sprint 3

## 1. Objetivo da Sprint

O objetivo da Sprint 3 foi evoluir a solução SafeVision Metaindústria, refinando o protótipo desenvolvido anteriormente, incluindo novos fluxos da aplicação e organizando o desenvolvimento utilizando práticas do framework Scrum.

---

## 3. Definition of Done — DoD

Uma tarefa é considerada concluída quando:

* Todos os requisitos da tarefa foram atendidos;
* A implementação, documentação ou protótipo foi finalizado;
* O resultado foi revisado por pelo menos um integrante do grupo;
* Não existem erros conhecidos que impeçam sua utilização;
* As alterações relevantes foram documentadas;
* O card correspondente foi atualizado no Trello;
* O item foi movido para a coluna "Concluído".
